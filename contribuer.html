Pull Request pas à pas

          
    
            
  1. Prépare ta fiche. Utilise le formulaire ci-dessus et clique sur « Copier la fiche JSON » (elle est déjà conforme), ou écris-la à la main d'après le guide de contribution.
    2. 
            
  2. Fais un fork du dépôt GitHub et clone-le (Node.js 22 ou plus récent).
    3. 
            
  3. Ajoute la fiche dans le tableau resources de data/resources.json.
    4. 
            
  4. Vérifie avec npm run validate:catalog puis npm test.
    5. 
            
  5. Ouvre la Pull Request et remplis le gabarit : explique l'utilité de la ressource.
    6. 
            
  6. Relecture. Un mainteneur relit ; la fiche reste « À vérifier » jusqu'à contrôle humain.
    7.
