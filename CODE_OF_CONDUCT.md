# Code de conduite

La communauté HashCode Cyber Library (dépôt GitHub, tickets, groupe WhatsApp) est un espace d'entraide pour apprendre et partager. Ce code s'applique à tous les espaces du projet.

## Nos engagements

1. **Respect et bienveillance.** Pas d'insultes, de harcèlement, de discrimination ni d'attaques personnelles.
2. **Cadre légal et éthique.** On n'aide jamais à attaquer un système sans l'autorisation écrite de son propriétaire. Les techniques offensives se discutent dans un cadre autorisé (labs, CTF, missions encadrées).
3. **Aucune donnée sensible.** Ne publie ni données personnelles, ni mots de passe, ni jetons, ni fuites de données, ni détails exploitables non divulgués.
4. **Sources et vérification.** Cite tes sources ; n'affirme pas sans avoir vérifié (voir la [politique de qualité](QUALITY.md)).
5. **Pas de spam.** Pas de démarchage commercial ni de liens hors sujet.

## Application

Les mainteneurs peuvent supprimer un message, fermer un ticket ou exclure un membre qui ne respecte pas ces règles. Pour signaler un comportement, contacte un mainteneur (ticket GitHub ou message privé dans le groupe).
