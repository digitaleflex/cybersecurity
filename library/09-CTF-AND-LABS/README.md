- [picoCTF](https://picoctf.org/) — CTF pédagogique.
- [TryHackMe](https://tryhackme.com/) — parcours guidés.

- [PortSwigger Academy](https://portswigger.net/web-security) — labs Web.

- [Root-Me](https://www.root-me.org/) — challenges communautaires.

Catégories : débutant, Web, réseau, systèmes, Active Directory, cloud, DFIR, reverse engineering et challenges événementiels.
