# 05 — Reverse Engineering

Comprendre le fonctionnement interne des logiciels et formats binaires pour l'audit, l'interopérabilité, la recherche et l'analyse défensive.

- [Ghidra](https://github.com/NationalSecurityAgency/ghidra) — framework de reverse engineering.
- [radare2](https://github.com/radareorg/radare2) — framework d'analyse de binaires.
- [Cutter](https://github.com/rizinorg/cutter) — interface graphique d'analyse.
- [Rizin](https://github.com/rizinorg/rizin) — framework de reverse engineering.
- [Awesome Reversing](https://github.com/alphaSeclab/awesome-reversing) — collection de ressources.

Sujets : formats exécutables, désassemblage, décompilation, débogage, analyse de flux et documentation.
