# Security Basics

## Ressources
- [NIST Cybersecurity](https://www.nist.gov/cybersecurity) — cadres, guides et publications.
- [CIS Critical Security Controls](https://www.cisecurity.org/controls) — contrôles de sécurité.
- [OWASP](https://owasp.org/) — sécurité applicative.
- [CISA Secure Our World](https://www.cisa.gov/secure-our-world) — hygiène numérique.
- [NIST CSRC](https://csrc.nist.gov/) — cryptographie et sécurité informatique.

## Sujets
CIA, gestion des risques, IAM, MFA, moindre privilège, chiffrement, sauvegardes, sensibilisation, vulnérabilités et gestion des correctifs.
