# Google Dorking & Search Engine Intelligence

## Ressources
- [Google Search operators](https://support.google.com/websearch/answer/2466433) — aide officielle.
- [Google Advanced Search](https://www.google.com/advanced_search) — formulaire de recherche avancée.
- [OSINT Framework](https://osintframework.com/) — ressources de recherche.
- [Bellingcat Toolkit](https://bellingcat.gitbook.io/toolkit) — workflows de recherche en sources ouvertes.

## Opérateurs usuels
- `site:` limiter à un domaine.
- `filetype:` filtrer par type de fichier.
- `intitle:` chercher dans le titre.
- `inurl:` chercher dans l'URL.
- `"expression exacte"` chercher une expression précise.
- `-` exclure un terme.

Les opérateurs ne donnent pas accès aux contenus privés ni aux systèmes non autorisés. Éviter toute recherche ou diffusion de secrets, identifiants ou données personnelles.
