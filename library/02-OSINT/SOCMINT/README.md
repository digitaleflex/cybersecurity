# SOCMINT — Social Media Intelligence

## Ressources
- [Bellingcat Toolkit](https://bellingcat.gitbook.io/toolkit) — méthodes d'investigation en sources ouvertes.
- [OSINT Framework](https://osintframework.com/) — outils classés par usages.
- [WhatsMyName](https://github.com/WebBreacher/WhatsMyName) — projet de recherche de présence publique par nom d'utilisateur ; vérifier les faux positifs.
- [Maigret](https://github.com/soxoj/maigret) — recherche de profils publics associés à un pseudonyme.

## Sujets
Analyse de profils publics, pseudonymes, publications, réseaux, chronologie, vérification et prévention des faux positifs.

Respecter les règles des plateformes et la vie privée. Ne pas chercher à accéder à des comptes privés.
