# SOCMINT — Social Media Intelligence

- [Bellingcat Toolkit](https://bellingcat.gitbook.io/toolkit) — méthodes d'investigation en sources ouvertes.
- [OSINT Framework](https://osintframework.com/) — outils classés par usages.
- [WhatsMyName](https://github.com/WebBreacher/WhatsMyName) — recherche de présence publique par pseudonyme ; vérifier les faux positifs.
- [Maigret](https://github.com/soxoj/maigret) — recherche de profils publics associés à un pseudonyme.

Sujets : profils publics, pseudonymes, publications, chronologie, vérification. Ne pas chercher à accéder à des comptes privés.
