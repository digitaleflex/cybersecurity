# Open-Source Investigation

- [Bellingcat Toolkit](https://bellingcat.gitbook.io/toolkit) — boîte à outils d'investigation.
- [InVID-WeVerify](https://www.invid-project.eu/tools-and-services/invid-verification-plugin/) — vérification audiovisuelle.
- [ExifTool](https://exiftool.org/) — inspection de métadonnées.
- [OSINT Framework](https://osintframework.com/) — répertoire de ressources.

Méthode : question de recherche → collecte → provenance → vérification indépendante → analyse → limites et niveau de confiance → rapport.
