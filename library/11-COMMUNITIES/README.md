# 11 — Communities

Annuaire de communautés, groupes d'échange, associations, conférences et réseaux professionnels. Vérifier les URL d'invitation avant publication.

- [OWASP Chapters](https://owasp.org/chapters/) — communautés locales OWASP.
- [ISACA Chapters](https://www.isaca.org/membership/local-chapter) — communautés professionnelles.
- [FIRST Teams](https://www.first.org/members/teams/) — équipes de réponse aux incidents.
- [DEF CON Groups](https://defcongroups.org/) — communautés locales de sécurité.
- [Bellingcat](https://www.bellingcat.com/) — communauté d'investigation open source.
- [Null community](https://null.community/) — communauté de sécurité informatique.

Pour chaque canal Telegram, Discord, YouTube, forum ou newsletter, noter URL officielle, langue, spécialité, type de canal, activité observée et date de vérification. Exclure les groupes de données volées, credentials, doxxing et accès non autorisés.
