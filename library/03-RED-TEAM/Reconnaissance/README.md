# Reconnaissance

- [OWASP Amass](https://github.com/owasp-amass/amass) — cartographie de surface d'attaque.
- [theHarvester](https://github.com/laramies/theHarvester) — collecte publique sur domaines et actifs.
- [ProjectDiscovery](https://github.com/projectdiscovery) — outils de découverte de surface.
- [Nmap](https://nmap.org/) — découverte et audit réseau autorisés.

Sujets : périmètre, inventaire, DNS, certificats, sous-domaines, exposition publique et validation non intrusive.
