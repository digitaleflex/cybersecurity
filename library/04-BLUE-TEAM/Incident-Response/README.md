# Incident Response

- [NIST SP 800-61](https://csrc.nist.gov/pubs/sp/800/61/r2/final) — guide de réponse aux incidents ; vérifier la révision courante.
- [CISA Incident Response](https://www.cisa.gov/incident-response)
- [TheHive](https://github.com/TheHive-Project/TheHive) — gestion de cas.
- [FIRST](https://www.first.org/) — communauté et standards de réponse.

Sujets : préparation, détection, analyse, confinement, éradication, restauration, communication et amélioration continue.
